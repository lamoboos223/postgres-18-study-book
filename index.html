How to study a chapter

  1. Read the mental model and the diagram.
  2. Read the deep explanation — do not skip “why PostgreSQL has this.”
  3. Type the examples. Do not only read them.
  4. Run the lab and the verification commands.
  5. Do the questions with the answers covered.

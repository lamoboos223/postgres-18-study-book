Answer key

1 B. Official cluster definition. A is HA marketing.

2 B. Default is replica. archive is a legacy alias mapped to replica, not a separate modern setting you should choose.

3 False. io_method is set at server start (postmaster). Restart required.

4 B. WAL first. Heap pages may still be dirty.

5 Permission denied for schema app. USAGE is required to resolve names.

6 listen_addresses still localhost — change it and restart. Then check firewall / pg_hba if bind is correct but auth fails.

7 B. Dump is a logical snapshot, not PITR.

8 Primary keeps WAL for that slot → disk growth → eventual outage. Drop or repair the standby.

9 VACUUM reclaims dead tuples in place for reuse. VACUUM FULL rewrites the table, takes a heavy lock, can return space to the OS.

10 Standby apply (queries, conflicts, IO). Compare LSN columns in pg_stat_replication. Check hot standby conflicts / max_standby_streaming_delay.

11 False. \c opens a new connection to another database.

12 pg_hba.conf (then role/password, then GRANT).

13 pg_combinebackup (full + incrementals in order) into one directory. summarize_wal was required when the incrementals were taken. pg_verifybackup is optional but exam-friendly.

14 recovery.signal = recover, then become a primary (file is removed). standby.signal = stay a replica.

15 False. The table must be created or truncated in the same transaction. FREEZE on a used table is rejected.

16 False. VIRTUAL is computed at read time. (You can still index it.)

17 DDL: CREATE. DML: INSERT. DCL: GRANT. TCL: COMMIT (or ROLLBACK / SAVEPOINT).

18 False. Cascade is async only. The mid-tier standby streams to others to offload the primary.

19 False. hot_standby is reads on a replica in recovery. One primary still writes. Two writers on streaming is split-brain, not HA.

20 EDB Postgres Distributed (PGD / BDR). Patroni, EFM, or repmgr still fail over one writer.

21 D. Port lives in postgresql.conf. initdb has no -p. ALTER SYSTEM needs a running server.

22 A. \o redirects later results. \g file runs the buffer once into a file.

23 B. -W prompts. -w never prompts. -X skips .psqlrc. -x is expanded output.

24 D. No password is set. The OS name is the default role name.

25 B. include_dir plus a quoted path. include is one file.

26 A. 32 TB at 8 kB pages. A single field is 1 GB. The database itself is not capped at 32 TB.

27 D. IDENTIFIED is not PostgreSQL syntax. Use PASSWORD.

28 A. A host line needs type, database, user, address, method.

29 D. ON SCHEMA grants schema rights (USAGE, CREATE), not table SELECT.

30 D.

31 C. temp_file_limit. temp_buffers is memory for temp tables.

32 C. Also SELECT setting FROM pg_settings WHERE name = 'data_directory';

33 D. -n includes a schema. -N excludes. -s is schema-only (no data). -S is a superuser name for disable-triggers.

34 A. The background writer writes dirty heap pages. The archiver copies finished segments.

35 B. The tablespace exists because WAL replay created it. The standby cannot drop it.

36 D. Many clusters, and it can change passwords. Default database is postgres, not template0. Tablespaces can be created in the UI.

37 B. Extract a tar-format backup into a directory first. pg_verifybackup reads that directory.

38 False. Since PostgreSQL 16 a publication can forward changes it received (origin = any, the default).

39 B. 1 GB segments: relfilenode, relfilenode.1, …

40 D.

41 A. The transaction starts read-only. A later INSERT fails. START TRANSACTION READ WRITE fails during recovery.

42 B. -X / --waldir relocates WAL. Segment size is fixed at initdb.

43 D.

44 B. ACCESS SHARE, same family as SELECT. DROP / VACUUM FULL still wait.

45 C. Prefer jsonb when you will index it. xml is a different type.

46 B. Then reload or restart, depending on each parameter.

47 A. Saving the file does not apply it. This parameter does not need a restart.

48 C. boolean is valid. Inline PRIMARY KEY builds a unique index.

49 D. pg_ctl promote / pg_promote() ends recovery without dropping existing sessions.

50 A. Plain REINDEX TABLE takes a lock that blocks writes.

Chapter 3 · EDB: PostgreSQL Installation

Install PostgreSQL 18 on pg-primary

Use the official PGDG Apt repository so you get version 18, not whatever Debian snapshot shipped. Install only on pg-primary. Leave pg-standby alone until Chapter 15.

1. What you need to know

Debian’s own apt install postgresql tracks Debian’s chosen major. This book needs PostgreSQL 18. Official postgresql.org Debian page: add the PGDG repo, then apt install postgresql-18.

The Debian packages run initdb for you and create cluster 18/main, managed by systemd and pg_ctlcluster.

EDB’s student labs are Rocky Linux + DNF (postgresql18-server, postgresql-18-setup initdb, data in /var/lib/pgsql/18/data). Same PostgreSQL 18; different packaging paths. Stay on Debian for this book.

3. Deep explanation

On vanilla PostgreSQL, you would create an OS user, run initdb -D ..., and start with pg_ctl. Debian wrappers:

  • pg_createcluster / the package post-install script — runs initdb with Debian paths.
  • pg_ctlcluster 18 main start|stop|reload|status — version-aware wrapper around pg_ctl.
  • pg_lsclusters — lists every cluster on the machine.
  • systemd unit postgresql starts all clusters; postgresql@18-main is the instance.

Config lives under /etc/postgresql/18/main/ even though data is under /var/lib/postgresql/18/main/. That split is Debian packaging, not a PostgreSQL-on-Windows law.

Remember. Pin the major: install postgresql-18, not the floating postgresql metapackage, or a new major can surprise you later.

EDB stresses environment variables after install. On Debian they are optional because pg_ctlcluster already knows the paths; still know them for the exam:

export PATH=/usr/lib/postgresql/18/bin:$PATH
export PGDATA=/var/lib/postgresql/18/main
export PGPORT=5432
export PGUSER=postgres
export PGDATABASE=postgres
Do not put PGPASSWORD in .bash_profile. The course mentions it; that is a secret on disk.

4. PostgreSQL 18 example

sudo apt install -y postgresql-common ca-certificates
sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh
Official automated repo setup from postgresql.org/download/linux/debian. The script adds the PGDG signed source. Answer its prompts if it asks; defaults are fine for this lab.
sudo apt update
sudo apt install -y postgresql-18
postgresql-18 is the server for major 18. It pulls a matching client. This runs initdb for 18/main and starts it.

5. Production perspective

🏭 Production note. Pin packages. Snapshot the VM before the first install if you like rollback. Do not install random PPAs. PGDG is the PostgreSQL project’s Apt repo — still review change control before adding it to a locked-down estate.

6. Hands-on lab

SSH to pg-primary only.

hostname   # must be pg-primary
sudo apt update
sudo apt install -y postgresql-common ca-certificates
sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh
sudo apt update
sudo apt install -y postgresql-18
⚠️ Destructive if you purge the wrong cluster. Do not run pg_dropcluster or apt purge postgresql-18 unless you intend to wipe this lab cluster.

7. Lab verification

psql --version
# PostgreSQL 18.x

pg_lsclusters
# 18 | main | ... | online | /var/lib/postgresql/18/main

sudo systemctl status postgresql --no-pager
sudo -u postgres psql -d postgres -c "SELECT version();"
sudo -u postgres uses Debian peer auth: the OS user name must match the role. The postgres OS user maps to the postgres superuser.

8. Troubleshooting

Symptom

apt install postgresql-18 cannot find the package.

Possible causes

  • PGDG repo script did not run.
  • apt update failed (clock, DNS, proxy).
  • Unsupported Debian codename.

Investigation

ls /etc/apt/sources.list.d/
sudo apt-cache policy postgresql-18
. /etc/os-release && echo $VERSION_CODENAME

Fix

Re-run the official apt.postgresql.org.sh script, then apt update. PGDG currently documents bookworm (12) and trixie (13).

Verification

apt-cache policy postgresql-18 shows a candidate from apt.postgresql.org.

9. Exam focus

🔥 Exam focus. initdb creates the cluster. Packages may hide that. Know data directory vs config directory on Debian. Know pg_ctl vs systemd. Know you must be the PostgreSQL OS user (or use sudo) to run initdb by hand.

10. One-minute revision

  • PGDG + postgresql-18 on Debian.
  • Cluster name: 18/main.
  • Config: /etc/postgresql/18/main. Data: /var/lib/postgresql/18/main.
  • Verify with pg_lsclusters and SELECT version().
  • Standby VM still has no PostgreSQL.

Review questions

Q1. Why not apt install postgresql on Debian for this book?

That metapackage follows Debian’s default major, which may not be 18. The book pins postgresql-18 from PGDG.

Q2. True / False. After the Debian package install you must run initdb yourself.

False for the default 18/main cluster — the package already initialized it. You still must know what initdb is.
